# PhoneStoreDB

## Database Tables

- Brands
- Phones
- PhoneCases
- Stores
- Employees
- Categories
- PhoneCategory
- Customers
- Orders

## Relationships

- One Brand has many Phones
- One Phone has many PhoneCases
- One Store has many Employees
- One Customer has many Orders
- Phones and Categories have Many-to-Many relationship through PhoneCategory
